# 새 대화에서 이어가기

다음 코드 블록을 새 대화 첫 메시지로 붙여 넣는다. 완료된 작업은 다시 만들지 않는다.

```text
이 프로젝트의 전 과목 구조도 작업을 이어가줘.

먼저 docs/구조도-확장-진행.md, README.md, git status -sb를 읽고 현재 상태를 확인해.
진행표의 미완료 항목부터 처리하고, 실제 검사에 통과한 항목만 체크해.

사용자 의도:
- 운영규정에서 승인된 가벼운 구조도를 조직법부터 마지막 과목까지 적용.
- 오늘의 목표 과제 안의 선택 안내 → 전체 지도 → 장·절·조문 묶음 도표 → 원문 읽기.
- 상단 구조도 메뉴는 모든 탭에서 열린다. 회독의 중복 큰 구조 보기 버튼은 사용자 요청으로 제거됨.
- 오늘의 표 비교·복원 과제는 해당 표 제목으로 이동한다. 육아휴직/육아기 근로시간 단축의 연령은 수록 원문 기준으로 구분하고 빌드에서 인용을 검증한다.
- 복습 범위는 날짜 없는 과목 기준으로 표시. 다음 스터디 추천은 9차 이후 과목 조합도 따르고, 일정 종료 후에도 2027년 5월까지 자율 복습 가능.
- 퀴즈·메모·강제 학습 단계나 추가 완료 체크를 만들지 말 것.
- 실제 원문 목차를 기준으로 장·절·전문·국제인도법 문단·유관법령 발췌를 구분.
- 모든 과목은 지도 안에서 선택 가능. 학습기록·기존 목표 개수·완료율은 보존.
- main에서 작업. 검증 후 커밋·push 승인됨. 하네스 자체는 로컬 커밋만 하고 에이전트가 git push를 실행한다. 게시는 별도 요청 없으면 하지 않는다.
- 하위 에이전트 없이 순서대로 작업.

주요 구현: op-study.js/css, card-review.js/css, study_tables.py, ux8.js, build_artifact.py.
진행과 인계: docs/구조도-확장-진행.md, .git/study-harness/handoff.md(있으면).
검증: python -X utf8 tools/study_harness.py validate
로컬 자동 커밋: python -X utf8 tools/study_harness.py stop
검증 후 소스가 달라지면 validate를 다시 해야 커밋된다.

Codex .codex/hooks.json은 최초 /hooks에서 사용자가 신뢰해야 실행될 수 있다.
신뢰를 에이전트가 위조하거나 우회하지 말고, 현재 세션에서는 위 명령을 직접 실행해도 된다.

컨텍스트가 부족하거나 불확실해지면 현재 상태·실패·다음 작업을 진행표에 남기고
python -X utf8 tools/study_harness.py checkpoint를 실행한 뒤,
사용자에게 새 대화에서 이 프롬프트로 이어가도록 안내해.
자동 컴팩트가 되거나 안 된다고 추측해서 보장하지 말 것.
```

## 훅과 검증

- Codex: `.codex/hooks.json`의 Stop/SessionStart/PreCompact.
- Claude: 기존 Stop은 `.claude/hooks/auto-commit.sh`를 거쳐 같은 Python 하네스를 실행한다.
- 검증 영수증: `.git/study-harness/verified.json` (소스 해시와 HEAD 포함).
- 체크포인트: `.git/study-harness/handoff.md` (진행표·프롬프트·Git 상태 복사본).
- 검증 실패·영수증 불일치·다른 작업의 stage·충돌이 있으면 자동 커밋을 보류한다.
- 커밋 허용 파일은 `tools/study_harness.py`의 OWNED에 명시한다. 관련 없는 파일을 자동으로 stage하지 않는다.
- Codex 훅 신뢰 안내: https://learn.chatgpt.com/docs/hooks
- 컴팩트를 강제로 끄거나 새 세션을 자동 생성하지 않는다.
