# 가채점 오류 사전 (Claude 판정 실수)

스터디 문제를 공식 답지가 나오기 전에 Claude 가 원문으로 가채점했다가 **틀린 것**. 문제를 내거나 채점할 때 같은 실수를 하지 않도록 먼저 읽는다.
`kb/study/답지.json` 에서 생성 — 직접 고치지 말 것.

- 대조 86문항 · 일치 80 · **가채점 오류 6** · 답지로 새로 넣은 문항 138

## 교훈 (먼저 읽기)

1. '최대·최장 N' 문장은 원문에 연장·예외 숫자가 있으면 X. 원칙 숫자만 맞는다고 O 로 두지 않는다. — `st2-이재길-10`
2. 기간 문장은 숫자 앞의 한정어('해당 계급에', '재직 중', '임신기간 중')까지 원문과 대조한다. 한정어가 빠지면 X. 같은 날 이재길 2번 ②는 '해당 계급에서'가 있어 O 였다. — `st2-황해민-8`
3. 두 조문을 이어 붙인 문장은 앞부분 요건(누구에게·왜)이 속한 조문 기준으로 판정한다. '출제 의도는 숫자 확인일 것'이라고 넘겨짚지 않는다. — `st2-황해민-9`
4. 원문 낱말을 바꾼 보기(건강검진→특수검진)는 상식상 포함 관계여도 X. 한 보기가 확실해 보여도 나머지 보기를 별표 비고까지 원문으로 확인한 뒤 고른다. — `st2-전영민-3`
5. 계산형 사례는 기준일부터 다시 센다: 월 개근 연차는 다음 달 1일에 '발생', '임용 후 9개월'은 수습 3개월이 끝난 임용일부터, 30일 미만 휴가는 제47조로 휴일을 뺀다. 선택지에 맞는 개수가 없다고 개수를 역추론하지 않는다. — `st2-전영민-4`
6. 기간 단위(연간·월·임신기간 중·재직기간 중)도 함정 낱말이다. 숫자가 같아도 단위가 바뀌면 X. — `st2-전영민-6`

## 문항별

### st2-이재길-10 — 가채점 O → 답지 X
- 근거: 운영규정:45 「휴가는 무급으로 하며, 연간 최장 10일…가족돌봄휴가 기간이 연장되는 경우 20일…25일) 이내]로 하며」
- 함정: 연장되는 경우 20일 → (빠뜨림)
- 왜: 무급은 맞지만 '최대 10일'이 아니다. 연장되면 20일, 한부모 25일 이내.
- 교훈: '최대·최장 N' 문장은 원문에 연장·예외 숫자가 있으면 X. 원칙 숫자만 맞는다고 O 로 두지 않는다.

### st2-황해민-8 — 가채점 O → 답지 X
- 근거: 운영규정:11 「5급직원으로서 해당 계급에 15년이상 근무하고」
- 함정: 해당 계급에 → (빠뜨림)
- 왜: '5급직원 중 15년 이상 근무'는 근무 기간이 어느 계급인지 빠졌다. 원문은 '해당 계급에' 15년.
- 교훈: 기간 문장은 숫자 앞의 한정어('해당 계급에', '재직 중', '임신기간 중')까지 원문과 대조한다. 한정어가 빠지면 X. 같은 날 이재길 2번 ②는 '해당 계급에서'가 있어 O 였다.

### st2-황해민-9 — 가채점 O → 답지 X
- 근거: 운영규정:28 「사회에 공헌한 공적이 현저한 자에 대하여는 포상 또는 표창을 행한다」
- 함정: 포상 또는 표창을 행한다 → 표창 및 포상 또는 포상금을 지급할 수 있으며
- 왜: 사회 공헌 공적은 제28조 포상제도(포상 또는 표창). '표창 및 포상 또는 포상금·300만원'은 제28조의2 창의적 제안 쪽이라 섞으면 틀림.
- 교훈: 두 조문을 이어 붙인 문장은 앞부분 요건(누구에게·왜)이 속한 조문 기준으로 판정한다. '출제 의도는 숫자 확인일 것'이라고 넘겨짚지 않는다.

### st2-전영민-3 — 가채점 ④ → 답지 ③
- 근거: 운영규정:별표1 「2016년 12월 31일 현재 기술직원으로 재직중인 간호조무사는 종전의 직렬 및 직종을 유지한다」
- 함정: 건강검진 → 특수검진
- 왜: ③ 2016년 입사자는 2016.12.31 현재 재직 중이라 기술직 유지 → O. ④ 공가는 '건강검진'이고 '특수검진'이 아님 → X.
- 교훈: 원문 낱말을 바꾼 보기(건강검진→특수검진)는 상식상 포함 관계여도 X. 한 보기가 확실해 보여도 나머지 보기를 별표 비고까지 원문으로 확인한 뒤 고른다.

### st2-전영민-4 — 가채점 ③ → 답지 ①
- 근거: 운영규정:45 「1개월간(1일부터 말일까지) 개근시 1일의 연차유급휴가를 부여한다」
- 왜: 가 5개(7~11월 개근분만 2026년에 발생, 12월분은 27.1.1 발생) / 나 A병원 0%(면허 24.3.1 이전 경력) / 다 병원장 / 라 휴일 빼고 20일 → 26.10.30 / 마 수습 3개월 뒤 임용(26.10.1)부터 9개월 → 27.6.30. 모두 틀려 0개.
- 교훈: 계산형 사례는 기준일부터 다시 센다: 월 개근 연차는 다음 달 1일에 '발생', '임용 후 9개월'은 수습 3개월이 끝난 임용일부터, 30일 미만 휴가는 제47조로 휴일을 뺀다. 선택지에 맞는 개수가 없다고 개수를 역추론하지 않는다.

### st2-전영민-6 — 가채점 O → 답지 X
- 근거: 운영규정:45 「임신 중인 직원은 임신기간 중 임신(태아)검진을 위해 10일 이내의 임신(태아)검진휴가를 반일 또는 1일 단위로 사용할 수 있다」
- 함정: 임신기간 중 → 연간
- 왜: 임신검진휴가는 '임신기간 중' 10일 이내. '연간'으로 바꿔 틀림.
- 교훈: 기간 단위(연간·월·임신기간 중·재직기간 중)도 함정 낱말이다. 숫자가 같아도 단위가 바뀌면 X.
