# 조직 구조 기준표

주체(누가 임용·징계·승인하나)를 판단할 때 쓰는 기준이다. 원문 정의 + 사용자 확인(2026-10-17)으로 만들었다.
원문이 바뀌거나 조직이 개편되면 이 표부터 고친다.

## 원문 정의 (직원 운영규정 제5조)
- **기관장**: 각 지사회장, 의료원장, 본사 직할기관장, 혈액관리본부장 (12호)
- **소속기관장**: 지사 및 혈액관리본부 소속기관의 장, 병원장 (13호)

## 단계
| 단계 | 무엇 | 장 | 비고 |
|---|---|---|---|
| 본사 | 본사 | 회장 / 사무총장 | 본사의 '기관장' 역할은 사무총장 (예: "해당 기관장(본사는 사무총장)") |
| 기관 | **지사** (여러 곳) | 지사회장 | 지사 하나하나가 혈액관리본부와 **같은 단계**의 기관. 실무 책임자는 사무처장(기관장급) |
| 기관 | 혈액관리본부 | 혈액관리본부장 | |
| 기관 | 의료원 | 의료원장 | 병원사업본부는 의료원 **안의** 조직(별도 기관 아님) |
| 기관 | 본사 직할기관 | 직할기관장 | 인재개발원, 재외동포지원본부, 인도법연구소 등 |
| 소속기관 | 지사 소속기관 | 소속기관장 | 봉사관, 센터 등 |
| 소속기관 | 혈액관리본부 소속기관 | 소속기관장 | 혈액원, 혈장분획센터, 혈액수혈연구원, 혈액검사센터. 헌혈센터·혈액공급소는 **혈액원 아래** 조직 |
| 소속기관 | 의료원 소속기관 | 병원장 | 모든 적십자병원은 의료원 아래 |

## 기관장급
기관장 + 소속기관장 + 사무처장, 혈액원 부원장, 병원 관리부원장 등 제18조 제2호 직위. 1급 직원은 보직과 무관하게 기관장급으로 본다(제59조).

## 자주 쓰는 판정
- **상급기관**: 지사·직할기관 → 본사 / 혈액관리본부 소속기관 → 혈액관리본부 / 병원(의료원 소속기관) → 의료원.
  예) 지사·직할기관·병원·혈액관리본부 소속기관 직원의 성희롱·성매매·성폭력 징계는 상급기관 보통징계위원회 (제59조⑥).
- **임용권(4급 이하 일반·전문직 등)**: 해당 기관장(본사는 사무총장). 혈액원장·병원장 같은 소속기관장은 팀장급 미만 일반직원의 **소속기관 내 전보권**과, 팀장급 미만 전문·특정·기술·기능직원·고용원의 임용권만 갖는다 (제18조의2 제2·4호).
- **징계 관할**: 기관장급 → 본사 특별(본사·지사·직할기관) / 혈액관리본부·의료원 특별(그 기관과 소속기관) · 팀장급 이하 → 기관 보통 · 소속기관 팀장급 미만 → 소속기관 보통 · 소속기관 팀(실·부)장급 → 혈액관리본부·의료원 보통 (제59조).
