# 기출 근거 DB (kb)

승진고시 4급·전직 **기출 432문항**(2018~2026)을 하나씩 읽어, 근거 조문과 출제 방식을 기록한 DB입니다.
Claude 는 대화가 끝나면 기억하지 못하므로, **카드를 만들거나 문제를 내거나 답을 검수할 때는 반드시 이 DB와 규정 원문을 먼저 읽고** 그 기준을 따릅니다.

## 원칙
1. **원문이 기준이다.** 근거는 규정 원문 문장을 글자 그대로 인용한다(`quote`). 검사기가 원문에 있는지 확인하며, 없으면 통과하지 않는다.
2. **해석하지 않는다.** 원문에 없는 내용으로 정답을 정하지 않는다. 확정할 수 없으면 `확인필요`로 둔다.
3. **기출이 출제 기준이다.** 어떤 조문이, 어떤 형식으로, 어떤 함정으로 나오는지는 기출에서만 가져온다.
4. **시점을 적는다.** 옛 기출이 지금 원문과 다르면(개정) `개정차이` 로 표시하고, 지금 원문 기준의 정답을 적는다.

## 파일
| 파일 | 내용 |
|---|---|
| `자료/조직도.pdf` | 대한적십자사 조직도 원본(사용자 제공) — 조직구조.md 의 근거 |
| `조직구조.md` | 기관(지사·혈액관리본부·의료원·직할기관)과 소속기관(혈액원·병원 등), 기관장급 구분 — 주체 판정 기준 |
| `kb_lib.py` | 규정 원문 사전(`규정:조문`), 기출 문항, 정규화 |
| `work.py` | 작업지: 문항 + 근거 조문 후보 / 조문 원문 보기 / 낱말 찾기 |
| `annot/<규정>.json` | 문항별 기록 (사람·Claude 가 읽고 작성) |
| `check_kb.py` | 검사 + 모음 생성 → `exam_kb.json`, `기출기준.md` |

## 문항 기록 형식
```json
{
  "id": "past-07-7",
  "form": "개수",                 // 아래 형식 중 하나
  "case": false,                  // 사례(가상의 상황)에 적용하는 문제인가
  "focus": ["주체", "기간·기한"],  // 무엇을 묻나 (여러 개)
  "level": 2,                     // 1~3
  "arts": ["운영규정:53"],        // 근거 조문
  "status": "확인됨",             // 확인됨 | 일부확인 | 확인필요 | 개정차이
  "points": [                     // 보기(가·나·①…) 또는 정답별 근거
    {"k": "가", "ok": false, "art": "운영규정:53",
     "quote": "원문 그대로",       // 여러 토막은 … 로 잇는다
     "trap": {"orig": "원문 낱말", "alt": "보기에서 바꾼 낱말"},
     "why": "한 줄 (원문 기반)"}
  ],
  "note": "선택"
}
```

### 형식 (form)
| 값 | 뜻 |
|---|---|
| `정오-옳은것` | 옳은 것을 고르기 |
| `정오-틀린것` | 옳지 않은 것을 고르기 |
| `개수` | 보기 중 옳은(옳지 않은) 것이 몇 개인가 |
| `조합` | 옳은 것을 모두 고른 조합(가·나 / ㄱ·ㄷ) |
| `빈칸` | 빈칸에 들어갈 말·숫자 고르기 |
| `계산` | 숫자들을 더하거나 빼서 답하기 |
| `짝짓기` | 항목과 주체·숫자를 연결 |
| `순서` | 절차·연혁 순서 |
| `OX` | 맞다/틀리다 |
| `주관식` | 직접 쓰기(단답·서술) |

### 묻는 것 (focus)
`주체`(누가 승인·의결·임명) · `기간·기한` · `인원·정족수` · `금액·비율` · `요건·사유` · `절차` · `정의·용어` · `효력·예외` · `구성·조직` · `열거`(몇 가지·무엇무엇) · `연도·연혁` · `개념`(국제인도법 등 서술형 이해)

### 난이도 (level)
| 값 | 기준 |
|---|---|
| 1 | 조문 하나, 원문 낱말 그대로, 함정 1개 이하 |
| 2 | 같은 규정의 여러 조·항, 숫자·주체 구분, 개수·조합형 |
| 3 | 여러 규정 결합, 사례 적용, 계산, 함정 2개 이상 |

### 함정 (trap)
틀린 보기가 원문의 **어떤 낱말을 무엇으로 바꿨는지**. `orig` 는 인용문 안에, `alt` 는 문제 글 안에 있어야 한다(검사기가 확인).
- 바꿈: `orig`·`alt` 둘 다 (예: 회장 → 사무총장)
- 끼워 넣음: `orig` 빈칸, `alt` 에 원문에 없는 말 (예: 가산 대상에 '음주운전' 추가)
- 빠뜨림: `alt` 빈칸, `orig` 에 빠진 원문 말 (예: 직렬 목록에서 '특수경력직원' 누락)

### 자료 해설 신뢰도
문제 파일의 해설(`ex`)은 일부가 자동 생성되어 **원문과 다르거나 정답과 맞지 않는** 경우가 있다. 그런 문항은 `note` 에 `자료 해설 오류:` 로 적고, 해설 대신 원문 인용을 따른다.
이 목록이 '시험에 나오는 함정 사전'이 되어 카드·문제 만들 때 쓰인다.

## 쓰는 법
```
python -X utf8 kb/work.py 운영규정 0 5          # 작업지
python -X utf8 kb/work.py --art 운영규정:53      # 조문 원문
python -X utf8 kb/check_kb.py                   # 검사 + exam_kb.json · 기출기준.md 생성
```
