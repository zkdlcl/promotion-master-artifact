# 전 과목 구조도 확장 · 진행표

## 요청과 완료 기준

- 운영규정에서 승인된 구조도 디자인을 조직법부터 앱의 마지막 과목까지 적용한다.
- 외우거나 입력하는 과제 대신, 전체 지도 → 장·절·조문 묶음 → 원문으로 연결하는 선택 안내만 제공한다.
- 오늘의 목표 카드 안에 배치하고, 다음 스터디·선택한 일일 범위에 맞춘다. 모든 과목은 지도 안에서 자유롭게 선택한다.
- 원문 목차의 장·절·전문·유관법령 구분과 조문 제목을 보존한다. 없는 관계·법적 절차를 만들지 않는다.
- 목표 수·완료율·학습 기록·배포 설정은 바꾸지 않는다. main에서 로컬 자동 커밋, 자동 push·게시는 하지 않는다.

## 작업 기록

- 2026-10-18: 사용자 요청으로 전 과목 확장과 로컬 자동 커밋을 새로 승인받음. 이전 ‘커밋하지 말라’보다 이번 요청을 우선한다.
- 구조도는 법률 판단을 생성하지 않고 수록된 목차를 시각화한다. 원문 데이터 자체는 수정하지 않는다.
- 브라우저 전 과목 검사 및 운영규정 기존 검사 통과. 조직법·정관·국제인도법·휴대폰 다크 스크린샷 직접 확인.
- 하네스 단위 검사 9개 통과: 검증 없는 커밋/오래된 영수증/다른 작업 stage를 보류하고, 검증 실패 시 이전 영수증도 무효화.
- Windows용 Codex 명령을 하위 폴더에서 실행해 루트 해석 및 JSON 출력 확인. 체크포인트 생성 확인.
- Codex 훅은 최초 `/hooks` 신뢰가 필요하며, 현재 실행 중인 세션에 자동으로 활성화되었다고 보장하지 않는다. 직접 검증·커밋 명령도 제공한다.
- 일일표의 마지막 날짜가 지난 뒤에도 운영규정으로 고정되지 않도록 다음 스터디 과목으로 넘어가는 경우를 검사했다. 사용자가 과거 날짜를 직접 고르면 해당 날짜의 과목을 따른다.
- 최종 `python -X utf8 tools/study_harness.py validate` 성공: 하네스 단위 검사 9개, 운영규정 지도, 전 과목 지도, ux8 27개, card 21개, law 51개. 영수증은 `.git/study-harness/verified.json`.
- 화면: 태블릿 가로/세로·휴대폰, 라이트/다크 확인. 새 구조도는 로컬에 반영되었고 게시된 아티팩트는 갱신하지 않았다.
- Stop 명령으로 승인된 구조도 변경만 main에 로컬 커밋한다. 원격 push는 하지 않는다. 커밋 해시는 `git log -1`로 확인한다.

## 컨텍스트와 인계 원칙

- 체크리스트는 검사에 통과한 항목만 완료로 바꾼다. 실패·미완료를 남기고 다음 작업을 한 문장으로 기록한다.

- 자동 컴팩트의 실제 활성화·잔여 토큰은 이 프로젝트가 판단할 수 없다. 훅은 인계 정보를 남기는 보조 수단이며 새 대화를 자동 생성하지 않는다.
- 새 에이전트는 이 파일·새 세션 프롬프트·git status를 읽고 확인된 다음 항목부터 이어간다.
